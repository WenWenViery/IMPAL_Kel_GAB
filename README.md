# InventarisAI (DATA-IN)

Aplikasi pendataan inventaris barang dengan fitur AI OCR untuk membaca nota otomatis.

| Fitur | Status |
|---|:---:|

## Tech Stack

- Next.js 14 (App Router) + TypeScript
- Tailwind CSS
- PostgreSQL
- bcryptjs + jose (JWT)
